# 文档按模块拆分重构

日期：2026-07-17
分支：`docs/split-per-module-docs`

## 背景

README「文档入口」按处理流程分 10 个模块索引，但两份操作性文档被多个模块交叉引用，
阅读时容易迷失（用户截图标出的问题）：

- 《自研RAG摄取部署与验收手册》被模块 1（上传）、2（解析，Parser Gateway 部署 §6.1.1）、
  5（检索，§6.6 验收）三处引用——内部混了上传摄取部署验收（主体）、Parser Gateway 部署、
  混合检索与 SSE 验收 + 审计验收（§6.6/§6.7）三种关注点；
- 《解析-切块-评估指南》被模块 2（解析）、3（切块）、评测框架三处引用——内部本来就是
  "一、解析 / 二、切块 / 三、评估"三个独立章节。

目标：**每个模块只引用属于自己的文档**。已排查全部文档引用关系，除这两份外没有其他
跨模块引用的文档；《总体架构》（architecture.md）是全局架构决策集，性质不同，明确不拆。

## 拆分方案

《解析-切块-评估指南》→ 按章节拆成 3 份后删除原文件（git 历史可追溯，不留空壳）：

| 新文档 | 内容 | 引用方 |
|---|---|---|
| `docs/解析指南.md` | 原"一、解析"章节 + 从手册挪来的 §6.1.1 Parser Gateway 独立部署 | 仅模块 2 |
| `docs/切块指南.md` | 原"二、切块 V3 五招式"章节 | 仅模块 3 |
| `docs/评估指南.md` | 原"三、评估"章节 + 文件地图 | 仅"评测框架"节 |

《自研RAG摄取部署与验收手册》→ 抽出两块，主体改名收窄范围：

| 文档 | 内容 | 引用方 |
|---|---|---|
| `docs/上传摄取部署与验收手册.md`（改名） | 实现边界、依赖、配置、API、状态机、上传/解析/索引验收（6.1~6.5，不含 6.1.1）、回滚、自动化 | 仅模块 1 |
| `docs/检索与审计验收.md`（新建） | 原 §6.6 混合检索与 SSE 验收 + §6.7 审计与可观测性验收 | 仅模块 5 |

## 防断链

- 挪走的三段（§6.1.1/§6.6/§6.7）在原手册对应位置各留一行指路，保持部署 runbook 的
  阅读顺序不断；
- 更新全部入站链接：README.md（6 处）、CLAUDE.md、CHANGELOG.md、
  `docs/自研RAG核心重构架构设计.md`、`eval/datasets/README.md`、`eval/datasets/标注指南.md`，
  以及新拆文档之间的相互引用；
- 完成后 grep 旧文件名全库验证 0 残留引用（`docs/archive/`、`openspec/changes/archive/`
  内的历史文档除外，归档不改写）。

## 范围扩展（实施中用户追加确认）

用户在实施过程中追加要求：README「文档入口」整体改为课程式章节结构（对照其学习材料的
目录），每章引用专属文档，子文档写清"每个功能怎么实现的、评估数字怎么来的"。确认后的
9 章结构：

1. RAG 整体架构（architecture.md + 重构设计，不拆）
2. 文档预处理与切分（上传手册 + 解析指南 + 切块指南，三个子环节各自专属）
3. Embedding 选型与向量化（新建 `Embedding指南.md`：bge-large-zh-v1.5→bge-m3 切换实录）
4. 检索召回·混合检索（新建 `混合检索指南.md`：实现结构+关键参数与数字来源）
5. 重排与检索优化（新建 `重排与检索优化指南.md`：拒答阈值校准全过程）
6. Query 理解与改写（新建 `Query理解与改写现状.md`：如实写"只有指代消解已实现，
   扩写/重写/HYDE/意图识别均为评估后暂缓"，不假装有功能）
7. 多轮对话与记忆管理（现有设计文档 + openspec 归档，含历史会话列表）
8. 上下文问答与引用溯源（防幻觉两道闸 + 引用抽屉/历史引用持久化，现有设计文档+验证报告）
9. 系统评估与上线优化（评估指南 + 检索与审计验收 + TODOS 性能/安全缺口）

新建的 4 份章节文档（3/4/5/6 章）只**收拢现有内容并指路**（README 条目、architecture
决策、eval 报告、TODOS 条目），不新编任何事实。

## Non-Goals

- 不改动任何文档的实质内容（只搬运/收拢+改链接，不重写结论、不更新过时表述）；
- 不拆《总体架构》（architecture.md）；
- 不动 `docs/archive/`、`openspec/changes/archive/` 里的历史文档。
