## 1. 系统概述

rag-kb 是面向企业团队的文档知识库与 AI 问答系统。核心工作流程：

```
上传文档 → 系统自动解析 → 进入知识库 → 向知识库提问 → AI 给出答案并标注来源
```

**当前已实现功能：**
- 账号登录与密码修改
- 知识库创建、切换、删除
- 文档上传、状态跟踪、删除
- 基于知识库的 AI 流式问答（实时输出答案 + 引用来源）
- 成员邀请、角色管理、密码重置（管理员功能）
- 团队创建与查看（管理员功能）

## 2. 角色与权限

系统有三种角色，权限逐级递增：

| 权限 | MEMBER（成员） | ADMIN（管理员） | OWNER（所有者） |
|------|:---:|:---:|:---:|
| 登录、修改自己密码 | ✅ | ✅ | ✅ |
| 创建/删除知识库 | ✅ | ✅ | ✅ |
| 上传/删除文档 | ❌ | ✅ | ✅ |
| 知识库问答 | ✅ | ✅ | ✅ |
| 查看成员列表 | ❌ | ✅ | ✅ |
| 邀请新成员 | ❌ | ✅ | ✅ |
| 修改成员角色 | ❌ | ❌ | ✅ |
| 重置成员密码 | ❌ | ✅（不含 OWNER）| ✅ |
| 创建/查看团队 | ❌ | ✅ | ✅ |
| 访问管理页面 | ❌ | ✅ | ✅ |

> **说明：** ADMIN 不能重置 OWNER 的密码，OWNER 是组织最高权限角色。MEMBER 只能使用知识库功能，无法进入管理页面。

## 3. 系统路由一览

> **前端地址**：`http://localhost:5173`（开发环境）  
> **后端 API**：`http://localhost:8090`（前端通过 `/api` 代理转发，用户无需直接访问）

### 前端页面路由

| 路径 | 页面 | 需要登录 | 所需角色 | 说明 |
|------|------|:---:|:---:|------|
| `http://localhost:5173/login` | 登录页 | ❌ | — | 系统入口，已登录自动跳转至 `/kb` |
| `http://localhost:5173/` | — | — | — | 自动重定向到 `/kb` |
| `http://localhost:5173/kb` | 知识库工作区 | ✅ | 全部 | 主界面：知识库列表、文档管理、AI 问答 |
| `http://localhost:5173/change-password` | 修改密码 | ✅ | 全部 | 账号密码修改页 |
| `http://localhost:5173/admin` | 管理中心 | ✅ | OWNER/ADMIN | 自动重定向到 `/admin/members` |
| `http://localhost:5173/admin/members` | 成员管理 | ✅ | OWNER/ADMIN | 邀请成员、修改角色、重置密码 |
| `http://localhost:5173/admin/teams` | 团队管理 | ✅ | OWNER/ADMIN | 创建团队、查看团队列表 |

**路由守卫规则：**
- 未登录访问任何需要认证的页面 → 自动跳转 `/login`
- 已登录访问 `/login` → 自动跳转 `/kb`
- MEMBER 角色访问 `/admin/*` → 自动跳转 `/kb`（无权限提示）

### 后端 API 路由（供开发者参考）

| 路径前缀 | 功能模块 | 认证要求 |
|---------|---------|---------|
| `POST /api/v1/auth/register` | 本地账号注册 | 无（Bootstrap 接口） |
| `POST /api/v1/auth/login` | 登录，返回 JWT | 无 |
| `POST /api/v1/auth/change-password` | 修改密码 | JWT |
| `GET/PATCH/DELETE /api/v1/knowledge-bases/**` | 知识库 CRUD | JWT |
| `GET/POST/DELETE /api/v1/documents/**`（`kbId` 为 query 参数） | 文档管理 | JWT |
| `POST /api/v1/knowledge-bases/{kbId}/query` | SSE 流式问答 | JWT |
| `GET/POST/PATCH /api/v1/members/**` | 成员管理 | JWT + ADMIN/OWNER |
| `GET/POST /api/v1/teams/**` | 团队管理 | JWT + ADMIN/OWNER |
| `GET /health` | 健康检查 | 无 |

## 4. 登录与账号管理

### 3.1 登录

系统**不提供自助注册**。账号由管理员（OWNER 或 ADMIN）在成员管理页创建，首次登录使用管理员提供的临时密码。

`[截图: 登录页面]`

**操作步骤：**
1. 在浏览器访问系统地址
2. 输入邮箱地址和密码
3. 点击「登录」

**登录失败常见原因：**
- 邮箱或密码错误：请确认大小写，或联系管理员重置密码
- 账号被锁定：连续多次登录失败后账号暂时锁定，等待一段时间后可重试或联系管理员

### 3.2 修改密码

建议首次登录后立即修改密码。

`[截图: 修改密码页面]`

**操作步骤：**
1. 点击右上角头像或用户名
2. 选择「修改密码」
3. 输入当前密码（临时密码）
4. 输入新密码（至少 8 位）
5. 再次确认新密码
6. 点击「确认修改」

> 修改密码后需要重新登录。

### 3.3 退出登录

点击右上角头像，选择「退出登录」。退出后当前会话立即失效。

## 5. 知识库

知识库是文档的组织单位。同一组织下可以创建多个知识库，用于按主题、项目或部门分类管理文档。

### 4.1 界面布局

登录后进入主工作区，界面分为两个区域，问答区占满主内容区（技术文档管理已移到独立页面，见「6. 文档管理」）：

```
┌─────────────────────────────────────────────────┐
│                   顶部导航栏                      │
├──────────┬────────────────────────────────────────┤
│          │                                        │
│  知识库   │              AI 问答                   │
│  侧边栏   │                                        │
│          │                                        │
│  [+ 新建] │                                        │
└──────────┴────────────────────────────────────────┘
```

### 4.2 创建知识库

`[截图: 新建知识库弹窗]`

1. 点击左侧侧边栏底部的「+ 新建知识库」
2. 在弹窗中输入知识库名称
3. 点击「确认」

创建完成后，新知识库出现在侧边栏列表中，可立即上传文档。

### 4.3 切换知识库

点击左侧侧边栏中的知识库名称，右侧内容区自动切换到该知识库的文档和问答界面。

### 4.4 删除知识库

`[截图: 右键菜单与删除知识库确认弹窗]`

1. 在侧边栏对知识库名称**右键单击**，弹出菜单
2. 选择「删除」，确认删除

> ⚠️ 删除知识库会**同时删除其中所有文档**，且操作不可撤销，请谨慎操作。
>
> 右键菜单同时提供「重命名」和「技术文档」（跳转到该知识库的文档管理页面，见「6. 文档管理」）两个入口。

## 6. 文档管理

技术文档管理是独立页面（路径 `/kb/:kbId/documents`），入口为在侧边栏对目标知识库**右键单击**，
选择「技术文档」。

> **权限说明：** 上传/删除文档仅 ADMIN、OWNER 可用，MEMBER 调用会被后端拒绝（403）。当前界面
> 未按角色隐藏上传/删除按钮，MEMBER 点击后会看到失败提示，而不是入口本身被隐藏。

### 5.1 上传文档

`[截图: 文档上传区域]`

1. 进入目标知识库的技术文档页面
2. 点击「上传文档」或拖拽文件到上传区
3. 选择要上传的文件（支持 PDF、Word、PPT、TXT 等格式）
4. 文档上传后进入解析队列

**支持的文件格式：** PDF、Word（.docx/.doc）、PowerPoint（.pptx/.ppt）、TXT、Markdown 等主流文档格式。

**单文件大小限制：** 50MB。

### 5.2 文档解析状态

文档上传后，系统需要一段时间进行解析、切块、向量化和索引。文档列表中每个文档都会显示当前状态：

| 状态 | 含义 | 说明 |
|------|------|------|
| **排队中** | QUEUED | 文件已上传，等待 Worker 领取处理 |
| **解析中** | PARSING | 正在提取文档内容 |
| **切块中** | CHUNKING | 正在按结构切分为可检索片段 |
| **向量化中** | EMBEDDING | 正在计算片段的向量表示 |
| **索引中** | INDEXING | 正在写入检索索引 |
| **可检索** | READY | 处理完成，可用于问答 |
| **失败** | FAILED | 处理失败，请重新上传或联系管理员 |
| **删除中** | DELETING | 正在清理该文档（不可再次删除） |

`[截图: 文档状态列表（包含不同状态示例）]`

> **注意：** 未到达「可检索」状态的文档不会被 AI 问答引用。请等待状态变为「可检索」后再发起问答。

系统会自动刷新文档状态，无需手动刷新页面。

### 5.3 删除文档

`[截图: 文档删除按钮位置]`

在文档列表中找到目标文档，点击操作列的删除按钮，确认后删除。删除操作不可撤销。

## 7. 知识问答

### 6.1 发起问答

`[截图: 问答界面]`

1. 在左侧选中包含相关文档的知识库
2. 点击右侧「问答」区域的输入框
3. 输入问题，按回车或点击发送

### 6.2 实时流式回答

发送问题后，AI 会**实时逐字输出**答案（流式输出），无需等待完整回答生成后再显示。

### 6.3 引用来源

`[截图: 点击 [资料N] 弹出的右侧引用抽屉]`

AI 回答正文中引用资料的地方会标注为 `[资料N]` 形式的角标，**点击该角标**会在右侧弹出抽屉，
显示对应文档、标题层级/页码/行号定位和原始文本片段。默认不在回答下方常驻展示引用列表，
只有被正文实际引用到的资料才有角标可点。

> 如果问题超出知识库中文档的范围，AI 可能回答「根据现有知识库内容，暂无相关信息」，这是正常情况。

### 6.4 网络中断处理

问答使用 SSE（服务器推送事件）实现实时流式输出。如果网络不稳定导致回答中断，重新发送相同问题即可。

## 8. 成员管理

> 本章节适用于 **OWNER** 和 **ADMIN** 角色。MEMBER 无法访问此页面。

### 7.1 进入成员管理

`[截图: 顶部导航「管理」入口]`

点击顶部导航栏的「管理」→「成员管理」，进入成员列表页。

### 7.2 成员列表

`[截图: 成员列表页面]`

成员列表展示当前组织内所有成员，每行显示：
- 邮箱地址
- 角色（OWNER / ADMIN / MEMBER）
- 操作按钮（修改角色、重置密码）

### 7.3 邀请新成员

`[截图: 新增成员弹窗]`

1. 点击页面右上角「新增成员」
2. 在弹窗中填写：
   - **用户 ID（SubjectID）**：用户的唯一标识（当前为本地账号的用户 UUID，或未来 OIDC 的 subject ID）
   - **角色**：选择 ADMIN 或 MEMBER（不能直接邀请 OWNER）
3. 点击「确认」

成功后新成员出现在列表中。系统会自动为该 SubjectID 关联到本组织。

### 7.4 修改成员角色

> 仅 **OWNER** 可执行此操作。

`[截图: 角色修改下拉框]`

1. 在成员列表中找到目标成员
2. 点击「操作」列的角色选择框
3. 选择新角色（OWNER / ADMIN / MEMBER）
4. 操作即时生效

> 注意：不允许将组织内**最后一名 OWNER** 降级，以防止组织失去所有者。

### 7.5 重置成员密码

当成员忘记密码时，管理员可以重置。

`[截图: 重置密码弹窗（显示临时密码）]`

1. 在成员列表中找到目标成员
2. 点击「操作」列的「重置密码」按钮（MEMBER 和 ADMIN 行可见；ADMIN 不能看到 OWNER 行的此按钮）
3. 确认重置操作
4. 系统生成**临时密码**并显示在弹窗中
5. **将临时密码告知成员**（系统不会自动发送通知）

> ⚠️ 临时密码**只显示一次**，请在关闭弹窗前记录并告知成员。成员首次用临时密码登录后，建议立即修改密码。

**权限限制：**
- ADMIN 不能重置 OWNER 的密码（防止通过临时密码完成权限提升）
- OWNER 可以重置所有人的密码（包括其他 OWNER）

> 本章节适用于 **OWNER** 和 **ADMIN** 角色。

## 10. 管理员操作速查

### 新成员入职流程

```
1. 管理员进入「成员管理」→「新增成员」
2. 输入成员的 SubjectID（邮箱账号的 UUID）和角色
3. 成员账号创建后，管理员点击「重置密码」获取临时密码
4. 将临时密码告知成员
5. 成员用临时密码登录 → 进入「修改密码」改为自己的密码
```

### 成员离职流程

> 当前版本暂无「删除成员」功能，离职成员的账号管理请直接操作数据库，或等待后续版本支持。

### 密码忘记了怎么办

| 情况 | 解决方法 |
|------|---------|
| 普通成员忘记密码 | 联系 ADMIN 或 OWNER 重置密码 |
| ADMIN 忘记密码 | 联系 OWNER 重置密码 |
| OWNER 忘记密码 | 联系系统管理员（IT 部门）通过数据库直接重置 |

## 附录：常见问题

**Q：为什么我上传的文档问不出结果？**  
A：检查文档状态是否为「可检索」（READY）。未到达该状态的文档不会被引用，请等待处理完成。

**Q：AI 回答的内容是否一定准确？**  
A：AI 的回答基于知识库中的文档内容，会标注来源。但 AI 可能存在理解偏差，重要决策请核对原始文档。

**Q：我问的问题 AI 不知道怎么回答？**  
A：如果问题涉及的内容不在当前知识库的任何文档中，AI 会提示无相关信息。可以尝试上传更多相关文档，或换一个知识库。

**Q：为什么管理页面我打不开？**  
A：管理页面（成员管理、团队管理）只对 OWNER 和 ADMIN 开放。如果你的角色是 MEMBER，请联系管理员升级角色。

**Q：我可以自己注册账号吗？**  
A：不可以。本系统不提供自助注册，账号必须由管理员创建。如需账号，请联系所在组织的管理员。
