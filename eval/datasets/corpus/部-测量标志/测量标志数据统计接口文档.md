## 通用说明

### 请求方式

所有接口均为 `GET` 请求

### 响应格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

### 响应码说明

| code | 说明 |
|------|----|
| 200  | 成功 |
| 500  | 失败 |

### 行政区代码说明

| 类型 | 格式     | 示例           |
|----|--------|--------------|
| 全国 | 100000 | 100000       |
| 省级 | XX0000 | 110000 (北京)  |
| 市级 | XXXX00 | 110100 (北京市) |
| 县级 | XXXXXX | 110101 (东城区) |

## 1. 各级标志点占比数量查询

### 接口描述

根据行政区代码、标志类别、标志等级等条件查询各级标志点占比数量，用于饼图展示。

### 请求地址

```
GET /geoSecurity/getPointGJZB
```

### 请求参数

| 参数名   | 类型     | 必填 | 说明                             | 示例     |
|-------|--------|----|--------------------------------|--------|
| xzqdm | String | 是  | 行政区代码                          | 100000 |
| bzlb  | String | 否  | 标志类别代码                         |        |
| bzdj  | String | 否  | 标志等级，多个用逗号分隔                   | 01,02  |
| type  | String | 是  | 统计类型：1-标志点总数，2-有效点位数量，3-完好点位数量 | 1      |
| pxfs  | String | 否  | 排序方式：1-按数量降序，2-按类型降序           | 1      |

### 响应参数

| 参数名               | 类型      | 说明        |
|-------------------|---------|-----------|
| total             | Integer | 总数        |
| list              | Array   | 各级标志点占比列表 |
| list[].dwsl       | Integer | 点位数量      |
| list[].bzdlx      | String  | 标志大类型名称   |
| list[].pcxxBzlbDj | String  | 标志类别等级代码  |

### 响应示例

```json
{
  "code": 200,
  "msg": "各级标志点占比数量查询成功",
  "data": {
    "total": 213349,
    "list": [
      {
        "dwsl": 85420,
        "bzdlx": "三角测量标志点",
        "pcxxBzlbDj": "01"
      },
      {
        "dwsl": 62150,
        "bzdlx": "水准测量标志点",
        "pcxxBzlbDj": "02"
      },
      {
        "dwsl": 45230,
        "bzdlx": "卫星定位测量标志点",
        "pcxxBzlbDj": "03"
      },
      {
        "dwsl": 15320,
        "bzdlx": "重力测量标志点",
        "pcxxBzlbDj": "04"
      },
      {
        "dwsl": 5229,
        "bzdlx": "仪器比对/计量鉴定测量标志点",
        "pcxxBzlbDj": "05"
      }
    ]
  }
}
```

## 2. 保管点位统计查询

### 接口描述

根据行政区代码查询标志点保管情况统计，包括保管点位数、保管人员数、人均保管数及保护等级分布。

### 请求地址

```
GET /geoSecurity/getCustodianStatistics
```

### 请求参数

| 参数名   | 类型     | 必填 | 说明    | 示例     |
|-------|--------|----|-------|--------|
| xzqdm | String | 是  | 行政区代码 | 100000 |

### 响应参数

| 参数名     | 类型      | 说明      |
|---------|---------|---------|
| bzdzs   | Integer | 标志点总数   |
| ybgdwzs | Integer | 已保管点位总数 |
| bgyzs   | Integer | 保管员总数   |
| rjbgdw  | String  | 人均保管点位数 |
| zdbhs   | Integer | 重点保护数   |
| ybbhs   | Integer | 一般保护数   |

### 响应示例

```json
{
  "code": 200,
  "msg": "保管点位统计查询成功",
  "data": {
    "bzdzs": 213349,
    "ybgdwzs": 185620,
    "bgyzs": 12580,
    "rjbgdw": "15",
    "zdbhs": 45230,
    "ybbhs": 140390
  }
}
```

## 3. 维护点位统计查询

### 接口描述

根据行政区代码和年份查询标志点维护情况统计，包括完好、迁建、废弃、已维护及无效点位数。

### 请求地址

```
GET /geoSecurity/getMaintenanceStatistics
```

### 请求参数

| 参数名   | 类型     | 必填 | 说明        | 示例     |
|-------|--------|----|-----------|--------|
| xzqdm | String | 是  | 行政区代码     | 100000 |
| year  | String | 否  | 统计年份，默认当年 | 2024   |

### 响应参数

| 参数名   | 类型      | 说明     |
|-------|---------|--------|
| whdw  | Integer | 完好点位数  |
| yqjdw | Integer | 已迁建点位数 |
| yfqdw | Integer | 已废弃点位数 |
| ywhdw | Integer | 已维护点位数 |
| wxdw  | Integer | 无效点位数  |

### 响应示例

```json
{
  "code": 200,
  "msg": "维护点位统计查询成功",
  "data": {
    "whdw": 124708,
    "yqjdw": 3250,
    "yfqdw": 8920,
    "ywhdw": 15680,
    "wxdw": 12350
  }
}
```

## 4. 巡查情况统计查询

### 接口描述

根据行政区代码和年份查询巡查情况统计，包括巡查人数、计划巡查数、实际巡查数及完成率。

### 请求地址

```
GET /geoSecurity/getPatrolStatistics
```

### 请求参数

| 参数名   | 类型     | 必填 | 说明        | 示例     |
|-------|--------|----|-----------|--------|
| xzqdm | String | 是  | 行政区代码     | 100000 |
| year  | String | 否  | 统计年份，默认当年 | 2024   |

### 响应参数

| 参数名      | 类型      | 说明       |
|----------|---------|----------|
| xcPerson | Integer | 参与巡查人数   |
| jhtotal  | Integer | 当年计划巡查数  |
| xctotal  | Integer | 当年实际巡查数  |
| xcl      | String  | 计划完成率(%) |

### 响应示例

```json
{
  "code": 200,
  "msg": "巡查情况统计查询成功",
  "data": {
    "xcPerson": 8562,
    "jhtotal": 50000,
    "xctotal": 42350,
    "xcl": "84.70%"
  }
}
```

## 6. 测量标志列表查询

### 接口描述

根据条件分页查询测量标志列表，支持按行政区、标志类别、标志等级、保护等级、巡查状态等条件筛选。

### 请求地址

```
GET /geoSecurity/getSurveyMarkList
```

### 请求参数

| 参数名      | 类型      | 必填 | 说明                 | 示例     |
|----------|---------|----|--------------------|--------|
| xzqdm    | String  | 是  | 行政区代码              | 100000 |
| bzlb     | String  | 否  | 标志类别代码             |        |
| bzdj     | String  | 否  | 标志等级，多个用逗号分隔       | 01,02  |
| bhdj     | String  | 否  | 保护等级：1-重点保护，2-一般保护 | 1      |
| xczt     | String  | 否  | 巡查状态               |        |
| pageNum  | Integer | 是  | 页码，从1开始            | 1      |
| pageSize | Integer | 是  | 每页条数               | 10     |

### 响应参数

| 参数名               | 类型      | 说明      |
|-------------------|---------|---------|
| total             | Integer | 总记录数    |
| list              | Array   | 标志点列表   |
| list[].smiId      | String  | 标志点ID   |
| list[].pcxxDm     | String  | 点名      |
| list[].pcxxDh     | String  | 点号      |
| list[].pcxxGljd   | String  | 概略经度    |
| list[].pcxxGlwd   | String  | 概略纬度    |
| list[].pcxxBzlbFl | String  | 标志分类代码  |
| list[].bzlbmc     | String  | 标志分类名称  |
| list[].pcxxBzlbDj | String  | 标志等级代码  |

| list[].pcxxGljgDm | String  | 管理机关代码  |
| list[].gljgmc     | String  | 管理机关名称  |
| list[].yxztmc     | String  | 有效状态名称  |
| list[].xcztmc     | String  | 巡查状态名称  |
